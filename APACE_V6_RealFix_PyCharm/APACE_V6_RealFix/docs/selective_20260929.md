# Selective calibration：二分类收益预测

用户已停止主动策略研究，授权仅预测fixed1是否有收益；预测有收益则fixed1，否则STOP。5折×3种子，subject-level bootstrap CI；无稳定优势则停止并转入校准收益/失败机制分析。

- 固定原外层划分与冻结A/B模型，使用已审计的328维未标注候选压力特征。重新逐人计算状态并污染参考target为NaN验证不变；不使用查询压力，特征标准化仅训练受试者。
- fixed1协议只由各折验证对象选择，所有算法相同。always-calibrate就是对每人执行fixed1，与fixed1完全等价；never-calibrate是STOP，不将别名当独立实验。
- 收益标签为Cnever−Cfixed1>0；C为归一化MAE+0.005×参考次数。正负标签只训练/验证监督，绝不作为输入。报告纯误差收益以区分成本导致的无净收益。
- 正则化线性logistic predictor：单个Linear+sigmoid；BCE+0.1×权重平方和，不惩罚截距，不类别重采样。Adam学习率0.01、batch32、200轮上限、至少30轮、耐心20；验证BCE恢复权重。固定种子7/17/27。
- 在验证集上以期望总代价选阈值，候选0、0.1…1、1.01（覆盖总是/从不校准），平局取较小阈值。验证集同时用于选fixed1、模型和阈值，测试集不参与；此复用可能过拟合验证对象，须作为限制披露。
- 所有参考片段结果精确平均，比较subject等权的误差、代价和采集次数，bootstrap2000次seed7；策略−基线使用配对受试者重采样。
- 稳定优势：每个种子相对fixed1代价差95%区间上界<0且至少4/5折均值更低，三个种子都满足才GO。本轮不沿用80%Oracle恢复率门槛，因为任务已变为收益二分类。
- NO_GO立即禁止追加预测器训练，退出2并进入描述性分析：收益/误差恶化/成本抵消类别、预测混淆、零校准误差分层、同一人参考片段效果异质性、各物理指标变化。不根据分析结果再拟合或筛特征。

原多步与单步主动策略均保持停止。三种子只重复收益分类器，不重复冻结基础模型；本数据有开发历史，训练折重叠，CI仅作描述性证据。原始误差和片段净收益只用于离线机制分析，不可用作部署特征，相关性不等于因果机制。

执行完成：三个种子均0/5折优于fixed1，NO_GO、退出2，已停止selective训练并完成描述性机制分析。131人净受益、36人误差增大、6人收益不足以抵消成本；24人因参考片段不同而有正负收益。152项测试、865次标签污染检查、519次模型回放、15个验证阈值复现均通过。报告：`outputs/selective_20260929/REPORT.md`。
