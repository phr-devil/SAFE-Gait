# G4学习Oracle收益：执行协议

用户明确要求：训练learned Value/Policy，比较fixed1、random1、uncertainty，计算Oracle Gain Recovery；低于80%或不能稳定优于基线时停止并诊断。

本轮仅重训现有Value模型，冻结已通过G3的5折预测/校准模型、目标标准化和人员划分。三个预定Value种子7/17/27，每折各训练一次；100轮上限，至少35轮、耐心20，按验证集分位数损失恢复最佳权重。输入仍为已采集参考的belief、剩余预算、协议剩余数量；不预先改架构，不在看结果后搜索超参数。

只有训练/验证对象的Oracle记录能训练/选模型。测试对象用于一次固定评估；对协议内所有可能采集片段求精确期望，无抽样噪声。预算2、lambda=0.005，策略取预测中位净收益最大协议，全部不大于0则STOP。

基线fixed1沿用G3验证集最优一次协议；random1均匀选择协议/片段，精确期望；uncertainty1以群体模型在候选压力embedding上的平均预测标准差选协议，仅采集一次，不读取候选参考真值。标准差使用已标准化的目标单位，避免cm/s与s直接相加。

主恢复率 = (受试者等权零校准平均代价 − learned平均代价) / (零校准平均代价 − Oracle平均代价)。保留零Oracle收益对象，不逐人除零，不截断负恢复率。另报告相对各基线的增量恢复率，避免将简单校准收益误判为规划收益。

GO要求三个种子都满足：主恢复率≥80%；相对每种基线的配对95% bootstrap代价差上界<0；至少4/5折平均代价更低。否则NO_GO、退出2、allow_active_optimization=false，不再启动改架构/调参/重复拟合。既定3种子×5折作为一个完整实验计算稳定性，不因中间有利结果提前挑选种子。

诊断包括：训练/验证损失差，首步状态相同但Oracle动作冲突，首步STOP/协议错误率，收益恢复与基线差。所有诊断都不反过来调整本轮测试参数。3种子仅代表Value初始化稳定性，非独立端到端重复；共享训练折的bootstrap仅作描述性估计。

检查清单：核心与CLI测试；独立审查；冻结输出协议；15次Value训练；173人×3种子完整评估；停止判定与原因报告。独立命令不自动接入A–E总训练器，也不启动G5。

已完成：127项测试通过；恢复率75.01%/73.85%/71.06%，九项基线差区间均跨0；G4为NO_GO，退出2，停止后续优化。15模型519次回放精确一致。153人处于首步状态相同但Oracle动作冲突的组；learned首步STOP为0人、Oracle为27人。报告：`outputs/g4_20260928/REPORT.md`。不得仅因G3为GO而自动重启本次已被G4中止的主动优化。
