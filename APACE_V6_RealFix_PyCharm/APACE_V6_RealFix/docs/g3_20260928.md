# G3 Oracle规划潜力评估

用户要求：优先完成G3，比较Oracle与固定1/2次、随机1/2次；Oracle没有明显优势时停止主动策略优化。

本次为已有5折模型的离线评估扩展，无训练和调参。预算2、lambda=0.005沿用原研究；模型、标准化、人员划分、校准/查询片段均保持原样。输出独立保存到 `outputs/g3_20260928`。

预先固定定义：每人代价为归一化MAE + lambda × 参考次数。Oracle控制协议，协议内未采集片段均匀随机、无放回；对所有分支精确积分，可基于已发生的结果继续或STOP。Oracle知道查询标签与全部反事实误差，属于乐观上限，不是可部署策略；不把测试Oracle记录送入训练。

固定1/2次：分别枚举长度1/2的协议序列，仅凭该折验证对象的等权期望代价选择；测试时不得基于标签提前STOP。若计划协议耗尽，按协议名称排序选择首个仍可用协议；仅校准池耗尽才少采。随机1/2次：均匀选可用协议，再均匀选片段；精确期望而非单次采样。

“明显优势”：对四种对照分别计算逐人相对代价改善，均值至少5%且配对受试者bootstrap 95%区间下界大于0，四项都满足才GO。任一项区间上界不足5%为NO_GO；其余不足证据为INCONCLUSIVE。后两者均设置allow_active_optimization=false，命令退出2，不启动任何优化。退出2需结合COMPLETED/G3决策区分研究中止与程序故障。

附加分解：报告各人事后最优的非自适应固定序列（含0/1/2次）与Oracle之差，区分“因人选择方案”与“第二步分支决策”的潜力。该对照同样是不可部署的事后上限，不参与主G3门槛。

限制：数据库已有开发历史；训练折重叠，bootstrap是描述性区间。此为独立G3离线研究决策工具，尚未插入A–E训练入口自动截断D阶段，不宣称G4/G5完成。

步骤：冻结协议和检查点哈希；测试DP/停止规则/非有限值/回放；独立审查；173名对象完整评估；报告决策、原因和可复核文件。

执行结果：173人全部回放通过；G3为GO，四项相对代价改善8.36%–9.85%，均值和区间均满足预设规则。Oracle与原有训练用动态规划逐人核对，最大代价差1.39e-17。第二步分支决策相对“逐人事后最优非自适应方案”仅额外改善1.01%；G3上限不能代替G4可学习性证据。本次未继续训练主动策略。
